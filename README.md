Общее описание
Программа представляет собой графическое приложение на Python с использованием библиотеки tkinter, которое позволяет искать пользователей GitHub через официальное API, добавлять их в избранное и сохранять список избранных локально в JSON файл.

Основные компоненты
Библиотеки:

tkinter - для создания графического интерфейса

requests - для выполнения HTTP-запросов к GitHub API

json - для работы с JSON файлом избранных

os - для проверки существования файла

datetime - для записи времени добавления в избранное

GitHub API интеграция:

Используется эндпоинт: https://api.github.com/users/{username}

GET запрос возвращает информацию о пользователе

Коды ответа: 200 (успех), 404 (не найден)

Функциональность:

Поиск: ввод имени пользователя, проверка на пустоту, запрос к API

Результаты: отображение в списке, кнопки действий

Избранное: добавление, удаление, обновление

Детали: просмотр полной информации о пользователе

Работа с JSON:

favorites.json - файл для хранения избранных

Структура: список словарей с ключами (login, name, html_url, avatar_url, added_date)

Обработка ошибок:

Пустое поле поиска

Пользователь не найден
